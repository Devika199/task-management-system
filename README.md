# Task Management System

A simple Task Management System developed using Django and Django REST Framework.

## Technologies Used

- Python
- Django
- Django REST Framework
- SQLite
- HTML
- CSS
- JavaScript
- Bootstrap
- jQuery

## Features

- User Registration
- User Login and Logout
- Add Tasks
- View Tasks
- Edit Tasks
- Delete Tasks
- Search tasks by title
- Filter tasks by status and priority
- Task status management
- Task priority management
- REST API for task CRUD operations

## Task Status

- Todo
- Progress
- Completed

## Task Priority

- Low
- Medium
- High
